# PyQuizMaster Pro

A lightweight, interactive browser-based quiz application built with zero external dependencies. Features real-time scoring, adaptive audio feedback, custom quiz configurations, and local history tracking.

---

## ✨ Features

* **Zero Externalities:** 100% self-contained code using native Web APIs (Web Audio API & HTML5 Canvas).
* **Interactive Gameplay:** Instant feedback, custom timers, and responsive layout.
* **Custom Configuration:** Filter questions by topic and adjust quiz length.
* **Local Persistence:** Tracks your top scores directly in the browser via `localStorage`.

---

## 🛠️ Tech Stack

* **Language:** HTML5, CSS3, JavaScript (ES6+)
* **Audio:** Web Audio API (Native sound generation)
* **Visual Effects:** HTML5 Canvas (Native particle/confetti system)

---
